# NOVA Task Brief Template

Use this format when you want Codex to move faster with less back-and-forth.

## Goal

What should change, in one or two sentences.

## Done Means

- Concrete outcome 1
- Concrete outcome 2

## Constraints

- Files or subsystems not to touch
- UI/DSP/RT safety constraints
- Preset compatibility or host compatibility constraints

## Validation

- Build target to validate
- Manual scenario to test
- Any regression you are worried about

## Context

- Related files
- Recent decisions
- Open blockers
